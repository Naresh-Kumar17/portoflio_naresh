# Naresh Kumar — Data Science & Software Portfolio

Interactive 3D constellation cosmos portfolio built for Naresh Kumar, Data Science undergraduate at FAST-NUCES Karachi.

## Features
- **3D Interactive Cosmos Universe**: Perspective-projected astronomical starfield & interactive celestial nodes built from scratch with pure HTML5 Canvas and mathematical camera physics.
- **Data Science Projects**: Showcasing machine learning classifiers (SVM handwritten digits), time-series forecasting models (Air Quality PM2.5/PM10), and accident severity analysis.
- **Enterprise Security Hardened**:
  - Sanitized form inputs & RFC-compliant validation
  - CRLF header injection and XSS defenses
  - Anti-bot invisible honeypot trap
  - Client-side rate limiting with cooldown safeguards
  - Content Security Policy (CSP) and production HTTP headers (HSTS, X-Frame-Options, X-Content-Type-Options)
  - Protected route guard architectures with RBAC
  - Cleaned repository with zero dependency vulnerabilities

## Tech Stack
- **Framework**: React 19, TypeScript
- **Bundler & Tooling**: Vite 8, Rolldown / Oxc
- **Styling**: Vanilla CSS with customized design tokens and glassmorphism
- **Animations**: Motion, Three.js canvas integration
- **Icons**: Lucide Icons

## Getting Started
```bash
npm install
npm run dev
```

Build for production:
