1. EXECUTIVE SUMMARY & OBJECTIVES
================================================================================
The primary directive of this project was to transform Naresh Kumar's portfolio
from a conventional modern web template into a replica of Nico Borja's signature
architectural design (https://nicoborja.com/). 

Key Core Goals:
1. Color Grading & Aesthetics: Replace generic neon accents with Nico Borja's
   curated Deep Obsidian Midnight canvas (#100E1A) in dark mode, Parchment
   (#EFE7D4) in light mode, and specialized spectral neon accents for specific
   knowledge domains.
2. 3D Interactive Cosmos / Constellation: Build a 3D perspective camera engine
   with volumetric nebula haze, twinkling background stars, Gaussian particle
   halos, travelling photon pulses along bezier curves, and dynamic camera
   rotation and drag physics.
3. Authentic Typography: Implement Fontshare's Cabinet Grotesk for bold architectural
   display titles, Martian Mono & JetBrains Mono for monospace code/data coordinates,
   and ZCOOL QingKe HuangYou for brand marks.
4. Content Tailoring for Naresh Kumar: Showcase Naresh's authentic academic
   and research journey as a BS Data Science undergraduate at National University
   of Computer and Emerging Sciences (FAST-NUCES) Karachi (2025–2029).
5. Automated Version Control: Initialize Git remote tracking and continuously
   commit and push all verified progress to GitHub (Naresh-Kumar17/protoflio_naresh).

4. 3D CONSTELLATION GRAPH ENGINE IMPLEMENTATION
================================================================================
File: src/components/NicoUniverse.tsx

Engine Mathematics & Features:
1. 3D Perspective Projection:
   - Calculates 3D world coordinates (x, y, z) into 2D screen coordinates:
     proj(wx, wy, wz) = [W * fieldCX + x1 * SC * Z, H / 2 - y1 * SC * Z, persp]
   - Applies dual-axis rotation (viewRot, viewTiltX) and subtle ambient rotation (curRot).
   - Perspective coefficient: persp = 5.5 / (5.5 - z2 * 0.5).
2. Deep Space Background Starfield:
   - 560 procedurally generated stars with randomized brightness powers and
     sinusoidal twinkle phases.
3. Volumetric Nebula Haze:
   - 1,500 particles distributed between connected node pairs using Box-Muller
     Gaussian noise transforms, creating authentic organic nebula clouds.
4. Quantum Particle Halos (Clusters):
   - Each node generates 18 to 60 orbiting orbital particles (n.cl) with
     dynamic radii, phase speeds, and brightness pulsations.
5. Photonic Edge Connections:
   - Curved quadratic Bezier arcs between connected nodes with travelling photon
     pulses animated along the curves via parametric interpolation.
6. Camera Physics & Navigation:
   - Smooth horizontal camera gliding (fieldCXt = 0.32 when gallery drawer opens,
     returning to 0.5 when closed).
   - Pointer drag for 3D tilt and pan; mouse wheel for smooth continuous zoom.

6. ROOT CAUSE ANALYSES (RCAS) & CRITICAL BUG RESOLUTIONS
================================================================================

Bug 1: "Still nothing showing on main screen just top bar and side map with dotted colors"
- Symptoms: React rendered the top bar and minimap, but the main canvas was completely black.
- Root Cause:
  The layout included `<canvas id="glass" />` at z-index 6, sitting in front of main
  canvas `#c` (z-index 1). In WebGL, initializing with `premultipliedAlpha: false` and
  calling `gl.clearColor(0,0,0,0)` causes the Windows ANGLE / DirectX compositor to treat
  the entire canvas buffer as an opaque black rectangle, completely obscuring canvas `#c`.
- Resolution:
  Completely removed the `#glass` WebGL canvas and its shaders in favor of hardware-accelerated
  CSS glassmorphism (`backdrop-filter: blur(28px) saturate(1.4)`), immediately revealing
  the 3D constellation universe.

Bug 2: "Colorful navbar is not working"
- Symptoms: Clicking category tabs did not trigger visual feedback or color changes.
- Root Cause:
  1. Tab buttons only toggled the `.on` class, whose CSS rule forced text color to
     `#05060A` without setting the dynamic region background color, rendering text invisible.
  2. Tab IDs did not map to hub node IDs, causing `setFieldFocus` to throw undefined errors.
- Resolution:
  Introduced `REGION_TO_HUB` mapping dictionary and updated `setTabsOn()` to dynamically
  apply each region's signature neon background color with high-contrast text and glowing box-shadows.

Bug 3: "Dark box covering the lower 70% of the screen with 'CLICK HERE TO RETURN TO THE MAP'"
- Symptoms: As captured in the user screenshot, a large dark block obscured the constellation.
- Root Cause:
  1. A hardcoded test override at the bottom of `NicoUniverse.css` (`#page { display: block !important; opacity: 1 !important; }`)
     permanently forced the case study reader to remain open.
  2. Clicking on map nodes triggered `openPage()` instead of merely selecting the node.
- Resolution:
  1. Removed the `#page` `!important` CSS rule.
  2. Integrated exact opacity and visibility synchronization inside `frame()`:
     `pageEl.style.opacity = String(pop); pageEl.style.display = (isPage || pop > 0.01) ? 'block' : 'none';`
  3. Decoupled canvas node clicks so clicking a node only focuses the cluster and opens
     the `#gallery` drawer, reserving full-page opens for explicit CTA button clicks.

Bug 4: Top Navbar Colliding with "NARESH KUMAR" Wordmark
- Symptoms: On screens under 1600px width, the left tabs overlapped the top-left brand title.
- Root Cause: `#tabs` was centered with `left: 0; right: 0;`.
- Resolution: Updated `#tabs` positioning to `left: 230px; right: 140px;` with horizontal
  no-scrollbar flex scrolling, guaranteeing zero overlap across all viewport widths.

Bug 5: Constellation Visual Clutter, Overlapping Text Labels & Compressed Layout
- Symptoms: All 28 node labels were colliding simultaneously, stacking text on top of adjacent
  circles and creating a dense, messy tangle in the center.
- Root Causes:
  1. Unfiltered label rendering: all child nodes drew labels at all times.
  2. 2D roll rotation in projection loop rotated the coordinate plane sideways into a narrow column.
  3. Dense coordinate packing within domain clusters (e.g., Analytics & BI having 8 tightly packed children).
- Resolution:
  1. Redesigned 3D spatial layout: expanded cluster hubs into distinct quadrant islands with generous breathing room.
  2. Converted camera rotation to 3D turntable yaw (rotating X and Z around vertical Y axis), preserving widescreen horizontal spread.
  3. Implemented smart progressive label disclosure: only flagship domain hubs display labels by default; child node labels smoothly reveal on hover, selection, cluster focus, or zoom (>= 1.5x).
  4. Added frosted glass backdrop pill badges with domain-colored accents to guarantee zero visual collisions with background stars and photon lines.
  5. Translated Spanish drawer and tooltip strings into professional English.
